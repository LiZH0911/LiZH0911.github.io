# HTML-CSS

## 一、HTML

### 1.1 **HTML入门**

**网页的组成**：

- HTML
- CSS
- JavaScript

**HTML（HyperText Markup Language）**：超文本标记语言，用于定义网页内容的含义和结构

- 超文本：超越了文本的限制，比普通文本更强大。除了文字信息，还可以定义图片、音频、视频等内容。
- 标记语言：由标签`<标签名>`构成的语言
- [官方文档](https://developer.mozilla.org/zh-CN/docs/Web/HTML)

**CSS（Cascading Style Sheet）**：层叠样式表，用于控制页面的样式（表现）。

- 
- [官方文档](https://developer.mozilla.org/zh-CN/docs/Web/CSS)
