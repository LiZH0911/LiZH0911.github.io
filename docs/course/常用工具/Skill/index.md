## 一、元 Skill

**skill-creator**：

- 创建 Skill 的辅助 Skill
- Codex 已内置，不用安装。

**[find-skills](https://github.com/vercel-labs/skills/tree/main/skills/find-skills)**：

- 找 Skill 的 Skill
- 没有完全同名内置项，通常不必安装。Codex 已内置 skill-installer，能列出官方 curated skills、从 GitHub 安装 Skill。

## 二、软件开发 Skill

**[superpowers](https://github.com/obra/superpowers)**：

- 给 Coding Agent 加一整套“软件开发方法论”：先澄清需求、写规格、做实现计划，再按 TDD / 任务拆分推进开发。
- Codex 未内置，但 **Codex App 插件市场可安装，值得考虑**。
- 适合希望严格执行需求澄清、计划、TDD、review 的开发者。
- 设计哲学：通过约束 AI 行为确保工程质量
- 适用场景：高标准、规范化的开发环境
- 平台支持：CC / Codex / **Cursor**

**[gstack](https://github.com/garrytan/gstack)**

- 设计哲学：模拟人类团队的工作流组织
- 适用场景：敏捷迭代、任务协作场景
- 平台支持：CC / Codex

**Front End Design**：

- 未内置 前端开发时推荐。
